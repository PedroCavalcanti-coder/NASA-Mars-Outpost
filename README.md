# NASA Mars Outpost

🚧 **Em desenvolvimento.** Estamos construindo o jogo agora.

Jogo educativo de colônia em Marte para o hackathon da NASA em Fortaleza (dias 14 e 15):
a equipe escolhe uma base, recebe a nave, cuida de energia, água, oxigênio e comida,
enfrenta eventos e toma decisões reais de exploração.
